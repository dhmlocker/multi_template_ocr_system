# 数据目录说明

本项目**不包含、不会生成**任何增值税发票、医院收费票据、快递寄件面单或其他业务表单数据。

请把你已经采集的数据按 `ImageFolder` 目录格式自行放入：

```text
data/
├─ train/
│  ├─ 增值税发票/
│  ├─ 医院收费票据/
│  └─ 快递寄件面单/
├─ val/
│  ├─ 增值税发票/
│  ├─ 医院收费票据/
│  └─ 快递寄件面单/
└─ test/
   ├─ 增值税发票/
   ├─ 医院收费票据/
   └─ 快递寄件面单/
```

目录名就是 CNN 模板分类标签；ROI 配置中的 `template_name`、ORB 参考模板目录名应与其一致。

训练脚本只读取这些目录。训练时的轻微旋转/亮度变化使用 torchvision 的**在线数据增强**，不会在磁盘中生成或保存新的业务表单文件。
